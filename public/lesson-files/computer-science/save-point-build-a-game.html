    Anatomy of a game

    This is Coin Cave, a tiny game made from the same parts you'll use. Play it for a minute and watch the state panel. The picture is drawn from that one dict, every single turn.

    LEVEL

    The map: walls, and where things start. A list of strings. It never changes while you play.

    state

    Everything that can change: where you are, hearts, score, your bag, which things are still around.

    rules

    Small Python functions. "When the hero touches a coin, change state like this."

    draw

    Reads state and paints the screen. It never changes anything.

    you press a key→move(state, dx, dy)→rules change state→screen redrawn from state↺

          Play it. Save it. Break it.
          
          
          Saving turns the whole state dict into text (JSON) and writes it to a file on the disk. Loading reads that text back into a brand-new dict. Quitting wipes the game's memory. Only the disk survives.

            Write the rulebook
            
          
            Every game is state plus rules that change the state. Write your game's rules so someone else could play it, invent one new piece, then decide what goes in the save file for your game and three games you didn't make.
            
        
            
        
            
          
            The recipe every game follows
            
          
            
            
            LEVEL
            what never changes. It ships with the game, so it never goes in a save.
            
            
            state
            everything that can change. This is what a save file holds.
            
            
            rules
            "when X happens, change state like this." Functions, the same for every player.
            
            
            loop
            read input → apply the rules → draw from state → repeat.
            
            
            save
            json.dumps(state) → text → a file on the disk.
            
            
            load
            the file → text → json.loads(text) → a brand-new state.
