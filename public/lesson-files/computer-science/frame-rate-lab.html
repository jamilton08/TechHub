Frame Rate Lab: from one picture to smooth motion

A screen never shows movement. It shows one still picture, then another, then another, fast enough that your eyes are fooled. In this lab you find out how fast is fast enough, why a game can run at 5 frames per second or 240, what the monitor's refresh rate has to do with it, and the one line of Python that makes your game move at the same speed on every computer. You write real pygame code that runs here and in the Python Arcade.

Seven levels

    • The Python you write here is the same pygame you use in the Python Arcade. This page has a recorder instead of a window: it runs your program for three seconds, records every frame it draws, and plays the recording back so you can scrub through it frame by frame.
