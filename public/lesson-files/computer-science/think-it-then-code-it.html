Read this first: logic doesn't care who runs it

A recipe, a fire drill, a math proof, and a Python program are the same kind of thing: a list of steps that anyone — or anything — can follow and get the same result. That's the whole trick behind computer science. If you can write the steps precisely enough that a stranger could follow them without asking a question, a computer can follow them too.

The difference is what a human fills in for free. Tell a person "add up the cookies" and they'll keep a running total in their head, do it for every person, and stop when the pile is empty, without being told any of that. A computer needs each of those spelled out. It turns out that's only four ideas:

  • Remember something→a variable
  • Do something again→a loop
  • Work with text→strings
  • Decide→if / else

Everything you write today is some mix of those four.

How this works

  • Each module has two halves. First you describe how you would handle the situation, in plain English. That unlocks the editor, where you write it in Python.
  • Run tries your program with the sample input. Check runs it against every test case. Checks are free; run them as often as you like.
  • Each module is worth 20 points (100 total). Hints cost 3 each, two per module. After three failed checks you can look at the solution; the module is then worth 10.
  • Your human answer isn't graded by the computer, but it's required and Mr. Cruz reads it.
  • At the end you download a result file and submit it in Google Classroom.
