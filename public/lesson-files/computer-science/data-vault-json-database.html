Data Vault: from one value to a JSON database

DATA VAULT
ROOM 333 ARCADE · HIGH-SCORE MACHINE · MEMORY: 0 BYTES

The Room 333 Arcade's high-score machine got wiped. Every name, every score: gone. You're going to rebuild its memory out of JSON, the text format almost every app, game and website uses to store and send data. You start with one single value. You finish with a real database you can search and change with Python.

Seven levels

    • 100 XP across seven levels. Every level unlocks the next one, and the stars on the level map show how much of a level you've cleared.
    • The clock starts when you click Start and stops when you finish.
    • Need more than one class? Use Save and continue later at the bottom of the page. A save file or a save code brings you back to this exact spot, and this browser also keeps your latest progress. (Inside, your save file is JSON too. It's sealed so nobody can edit it.)
    • At the end you download a result file and submit it in Google Classroom. You can also download the database you designed.
