Packet Trail: where is my packet?

In Packet Run you built a network and caught a hacker. Now follow single packets through it, one decision at a time: which address goes where, which router sends it on, where it gets lost, and exactly what a hacker on the path gets to see. Every question shows you where the packet is right now, and what's written on it.

Five scenarios

    • 25 questions, one at a time, each worth 4 points. They build on each other, so they unlock in order.
    • Wrong answer? You get a hint about what you missed and one more try, for 2 points. After that, the answer and the reason are shown.
    • After each question, watch the packet actually take the trip.
    • The clock starts when you click Start and keeps counting across sittings. Need more than one class? Use Save and continue later under the map — a save file or code brings you back to the same question. At the end you download a result file and submit it in Google Classroom.
    Enter your name first. It goes on your result file.
