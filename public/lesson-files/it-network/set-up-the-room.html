Set up the room.

Yesterday you watched packets travel. Today you build the network they travel on, then write the packets yourself.

Room 216 just got a new router, a laptop, and a printer. Nothing is plugged in and nothing is configured. There's a wall jack that leads to the school network. You have the network plan on a sticky note. Make the three boxes talk — then prove it by writing every packet by hand: where it's from, where it's going, and which door it knocks on.

Two phases

  • Phase 1 — Set up (40 points). Plug the cables into the right ports. Configure the router through its web page, the laptop through the Windows dialog, the printer through its front panel. Press Check the network when you think it's right. The first check is free; after that each check that still fails costs 4.
  • Phase 2 — Write the packets (60 points). Six packets, 10 each: ping the router, ping the printer, answer as the printer, print a page, ask for a name, answer as the DNS server. Every wrong send costs 3, and the board shows you where the packet died.
  • The Reference tab has the plan, the ports, and the rules. The Plan tab is your sticky note. Nothing here is a trick — it is exactly the job a technician does on a Tuesday.
