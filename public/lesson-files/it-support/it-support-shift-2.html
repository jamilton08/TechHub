      Troubleshooting method (CompTIA)

      1. Identify the problem — question the user, note recent changes.
      2. Establish a theory of probable cause.
      3. Test the theory. If it fails, form a new theory.
      4. Plan the fix.
      5. Implement it and verify the system works.
      6. Document what happened.

      Where does it break? Test the layers in order

      LinkPort LEDs on, Wi-Fi shows connected. No link = cable, jack, patch, switch port, or radio. Software can't fix it.
      Addressipconfig. 192.168.x.x / 10.x.x.x = DHCP worked. 169.254.x.x = no DHCP server answered (APIPA). Gateway blank = same story.
      Gatewayping the default gateway. No reply = the local network isn't working.
      Internet by IPping 8.8.8.8. Replies = the internet is reachable, whatever the browser says.
      Internet by nameping google.com / nslookup google.com. Fails while 8.8.8.8 works = DNS.
      The appEverything above works and one program doesn't = look at that program.

      Command cheat sheet

      ipconfig /allEvery adapter: IP, mask, gateway, DHCP server, DNS servers, MAC.
      ipconfig /release · /renewGive back the DHCP lease and ask for a new one. Fails if there's no link.
      ipconfig /flushdnsForget cached name lookups.
      ping <address or name>Is it reachable, and how fast? "Could not find host" = DNS, not the network.
      nslookup <name>Which DNS server is being asked, and what it answers.
      tracert <name>Every hop on the way. Shows where packets stop.
      sfc /scannowChecks Windows system files. Does not check third-party drivers.

      Addresses: DHCP, static, reservation

      DHCP hands out addresses automatically and can hand out a different one after a reboot or outage. A static address is typed into the device. A DHCP reservation ties one address to one MAC on the server — best of both. Anything other machines connect to (printers, servers, cameras) needs a fixed address. Anything typed by hand on a client (a manual DNS server, a static IP) overrides DHCP and survives "forget network," reboots, and uninstalls.

      Printers

      Windows "Offline" means nothing answers at the address in Properties → Ports. The printer's own panel can say Ready at the same time. Network printers use a Standard TCP/IP port (RAW, port 9100). Restarting the Print Spooler clears stuck jobs; it doesn't change where they're sent. Reinstalling the driver changes how Windows talks to the printer, not where.

      Blue screens

      Stop codeThe category. What failed: xxx.sys is the driver, when Windows knows.
      DRIVER_IRQL_NOT_LESS_OR_EQUAL (0xD1)A driver touched memory it shouldn't. Almost always a bad or old driver.
      IRQL_NOT_LESS_OR_EQUAL (0xA)Same idea; a driver or, less often, RAM.
      PAGE_FAULT_IN_NONPAGED_AREA (0x50)Bad driver, bad RAM, or a corrupt system file.
      KERNEL_DATA_INPAGE_ERROR (0x7A)Couldn't read from the disk. Check the drive.
      WHEA_UNCORRECTABLE_ERROR (0x124)Hardware reported a fault: CPU, overclock, power, heat.
      Kernel-Power 41"The PC restarted without shutting down" — the result of a crash, not the cause. Look for the BugCheck event next to it.
      MinidumpC:\Windows\Minidump. BlueScreenView or WinDbg reads it and names the driver.

      Driver rules: from the manufacturer, digitally signed, made for this version of Windows. A crash that starts when a device is added is that device's driver until proven otherwise.

      Slow computers

      Task Manager → Processes, sorted by CPU, memory or disk, shows who is using the machine. Startup apps show who starts with it. Settings → Installed apps sorted by date shows what arrived together: several programs installed in the same minute is a bundle. A "PC cleaner" that finds a thousand problems is selling you the fix for problems it invented. Two antivirus products at once fight each other; Windows Defender alone is the standard.

      Login problems

      "Password is incorrect"Windows got something that didn't match. Caps Lock, Num Lock, or the keyboard layout (Win+Space switches it; the indicator is on the login screen).
      "Account is locked out"Too many wrong tries. An admin unlocks it.
      "Password has expired"Policy. Change it.
      TestSame password on another PC, or via the On-Screen Keyboard. If either works, the account is fine.
