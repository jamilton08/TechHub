      Setup order that works

      1. Cables: wall jack → router WAN. Laptop and printer → router LAN ports.
      2. Power the router first. Nothing gets an address until it's up.
      3. Power the laptop. Check it got a 192.168.x.x address (ipconfig).
      4. Open the router's admin page in Edge. Change the admin password. Set up Wi-Fi.
      5. Power the printer. Give it a fixed address (static, or a DHCP reservation). Print its network configuration page.
      6. On the laptop, add the printer by IP address, pick the right driver, print a test page.
      7. Document it. Call it in.

      WAN vs LAN

      The WAN port (usually a different color) faces the outside world — the ISP, or here, the school network. The router gets its address from whatever is on that side. The LAN ports face your room; the router hands out addresses there with DHCP. Put the outside on a LAN port and your router's DHCP server starts answering the whole school. The network office calls that a rogue DHCP server, and they can see which jack it came from.

      What an address tells you

      192.168.1.xHanded out by this router's DHCP (pool .100–.199). Gateway 192.168.1.1 = the router.
      169.254.x.xAPIPA. Windows asked for an address and nobody answered: router off, cable in the wrong port, DHCP disabled. Fix the link, then ipconfig /renew.
      10.0.33.xThe school network. You're on the wrong side of the router — the printer can't be reached from there.
      Media disconnectedNo link light. Cable unplugged, or the device at the other end is off.

      DHCP, static, reservation

      DHCP hands out addresses automatically from a pool — and can hand out a different one after a reboot or power blink. Routers don't promise the same address twice. A static address is typed into the device; pick one outside the pool (here: .2–.99) with the right mask (255.255.255.0) and gateway (192.168.1.1). A DHCP reservation ties one address to one MAC on the router, so DHCP always hands that device the same one. Anything other machines connect to — printers, servers, cameras — needs one or the other. A reservation takes effect the next time the device asks for an address: re-apply its network settings or power-cycle it.

      Default credentials

      Every router ships with the admin login and Wi-Fi key printed on a sticker. Everyone who has ever seen that model's sticker knows them. Change the admin password first; the Wi-Fi name and key second. Do Wi-Fi changes over a cable — if you're on the Wi-Fi you're changing, you'll cut yourself off.

      Adding a network printer in Windows

      Windows discovery often finds nothing (it depends on the printer's broadcast settings and the switch). The reliable way: Add manually → Add a printer using an IP address. Windows creates a Standard TCP/IP port (RAW, port 9100) pointed at that address. Then pick the driver for the exact model on the printer's label. "Generic / Text Only" prints letters and nothing else; a different model's driver makes the printer reject the job. Later, "Offline" means nothing answers at the port's address — check the printer's address, not the driver.

      Printer front panel

      Menu → Network → Wired LAN → TCP/IP holds the boot method (Auto = DHCP, or Static) and the address fields. Nothing changes until you choose Apply. Print Reports → Network Config prints what the printer is actually using, plus its MAC address — which you need for a reservation.

      Command cheat sheet

      ipconfig · /allEvery adapter: IP, mask, gateway, DHCP server, DNS, MAC.
      ipconfig /renewAsk DHCP for an address again. Fails if there's no link.
      ping <address>Is it reachable? Router first (192.168.1.1), then the printer, then 8.8.8.8, then google.com.

      What the supervisor checks

      She flips the power strip and waits. The router forgets its lease table and starts handing out addresses from a fresh spot. If the printer's address changed, every port that pointed at it is now Offline. Then she reads the job sheet line by line.
